# 构思第 2 轮（2026-10-23）

## 反常识角度
- 可能错的假设：检索是主要瓶颈（实测读者没用上约 20 vs 没取到约 15）；读者应拿“最相关”证据（最相关的往往是最像答案的干扰项）；必须写时压缩；越结构化越好；强读者不需要记忆（仍需“看全”）；全库扫描太贵（1M 约 8K 条，很便宜）。
- 方法 A 最小混淆上下文（主推，自估 7）：选上下文目标改为 max 覆盖(答案证据) − λ·混淆度(S)；混淆度 = 与答案证据同实体/同话题/时间相邻但不含答案的记录占比；只选不改写；需要旧值的题把竞争者按时间成对呈现。近邻：First Drop of Ink 2605.10828（只诊断）、MMR（多样性）、2605.27294。最小试验：1M 开发集“信息在上下文却答错”的题，等字数下 原样 / 删竞争者 / 删同字数无关。风险：更新/时序题需要竞争者；打标签成本≈全扫描。
- 方法 B 成员判定与聚合分离（自估 6–6.5）：读者只写谓词+聚合算子，便宜模型逐条判成员，确定性程序聚合；近邻 LOTUS/BARGAIN、TA-Mem 2603.09297。

## 理论优先
- A CEGAR-Mem 封闭世界反例精化（主推，自估 7）：读者给候选答案 a + 证据 E；便宜模型逐条扫全部记录判“这条推翻 a 或给 a 补一项吗”，有反例加入 E 重答，到不动点。目标 ∀r ¬refute(a*, r)。性质：列表/计数单调、≤|记录| 轮停；漏项概率 ≤ β（验证漏检率），m 个独立提示约 β^m；若 β < β'（相关性扫描漏检率）则等算力严格优于全扫描。记忆特有：个人记忆是封闭世界、账本不可变，“无反例”即完整性证明，可证实“从没提过”。近邻：CounterRefine 2603.16091（按答案再检索一次）、BARGAIN（抽样认证）、2603.22608（逐条判对汇总仍错）。关键试验：测 β vs β'。
- B 记忆当重复码解码（因子图 + 多数表决界 + Viterbi 排序），自估 6–6.5；风险：BEAM 多数事实只提一次。
- C 写时同态汇总（count/set/min/max/latest 增量维护），自估 5.5–6。
- D 在线物化派生视图（ski-rental 2-竞争），自估 5。

## 场景优先
- 场景现状：MemoryArena（ICML26，2602.16313）所有记忆方法平均 SR ≤0.23、团体旅行≈0，跟进仅 MAGE 2606.06090、MemoryLake 2608.13883；LongMemEval-V2（2605.12493，网页经验 25M–115M token）RAG 48.5、Codex 69.3、AgentRunbook-C 72.5 但每题 108–186 秒，“环境坑点”类均 <52%；OAKS（2603.07392）开源模型约 33%，记忆系统不如朴素 RAG，错误分过度更新/更新不足；VitaBench 2.0（2605.27141）记忆均不如全上下文；2603.29231 小模型加记忆脚手架全部变差。
- A 承诺核验（自估 7）：记忆写成可判真假的承诺谓词，每次关键动作前便宜模型逐条扫全部承诺判通过/违反，有违反带反例修改；评 MemoryArena + VitaBench 2.0。近邻 User as Code、MAGE、PAHF 2602.16173。
- B 预期违背记忆（自估 7–7.5）：写入时读者先预测每步结果，只存预测错的残差（意外效果、隐藏前提、状态跳变）；MDL/惊讶度视角，解释“强读者收益小”。评 LongMemEval-V2。近邻 D-MEM 2603.14597、EM-LLM、2606.03787、AMA-Agent 2602.22769、AgentRunbook。
- C 序贯变点更新 CUSUM 记忆槽（自估 6.5–7）：评 OAKS、StateMemBench 2608.19652。

## 独立评分
- CEGAR-Mem：新颖性 4.5、单一方法 7、理论 3、胜强对照 4、强读者 4.5、上限 5.5–6 → **偏向不做**。CounterRefine 2603.16091 已做“按候选答案找反证”（单轮）；β≈β'（补项判断≈相关性判断）、多提示漏检高度相关、封闭世界被写入缺失推翻；做完会退化成带认证的语义过滤。门槛试验（若做）：β ≤ 0.6β'、3 提示联合漏检 ≤ 2β²、端到端 luna +4 / 强读者 +2。
- 最小混淆上下文：新颖性 4、单一方法 6、机制 5、效果 4、强读者 3、上限 5.5–6 → **改了再做（只做诊断试验）**。First Drop of Ink 2605.10828 已说明过滤收益主要来自变短而非去干扰；AdaGReS 2512.25052 等相关度−冗余选择、Jin et al. 2410.05983（难负例+重排）、Rosetta Memory 2606.07711；致命循环：判“竞争者”需要便宜模型先答对→退化成全库扫描。要到 7：混淆度做成与读者无关、事前可测并能预测错误率；算子改为“保留但消歧”；等算力赢全库抽取与 Hindsight+mem0 提示且强读者也赢。
- 预期违背记忆：新颖性 3.5、单一方法 7、可行 4、效果 4.5、上限 5–5.5（改完至多约 6.5）→ **倾向不做**。MemoWM 2610.10778（10-07）已用世界模型先验压缩、只存超出先验的信息，且评测含 LME-V2 Small；D-MEM、NEMORI（ACL26）、WebATLAS 2510.22732 亦近。LME-V2 核实：451 题、Small ~100 轨迹/25M token、开源、排行榜空；“坑点”类约 29 题，Codex Small 58.6（非全部 <52）。
- 承诺核验：新颖性 4、单一方法 4、可行 6、效果 5、上限 5.5–6 → **改了再做**。近邻 LedgerAgent 2606.20529（账本 + 工具调用前查策略规则）、CaMeLoT 2609.18674（执行前模型检查 + 反例修复）、Pre-Action Verification 2609.11957、Stale Constraints 2608.25553、HiMAP-Travel 2603.04750、VeriGuard 2510.05156。MemoryArena 核实：701 题、开源、团体旅行 SR 全为 0、记忆类平均 SR 0.13–0.14；VitaBench 2.0 直接给标准偏好也只有约 52（瓶颈在用上偏好）。

## 第 2 轮小结
四个候选独立评分全部 5–6。新颖性普遍 3.5–4.5：2026 年记忆方向论文极多，任何单一“机制”几乎都有近邻（CounterRefine、First Drop of Ink、MemoWM、LedgerAgent 等）。

## 策略调整（第 3 轮）
两轮共 8 个候选都卡在“新颖性 ~4 → 上限 ~6”。在这么挤的领域，7–8 分更现实的来源是：在一个现有方法普遍失败、提升空间极大的难基准上，先做诊断找到真正的病因，再给出直击病因的方法并取得大幅提升（效果大可以弥补中等新颖性），同时在第二个基准上验证。候选难基准：MemoryArena（SR ≤0.2，团体旅行 0）、LongMemEval-V2（排行榜空，最好方法每题 2–3 分钟）、OAKS（记忆系统不如朴素 RAG）、VitaBench 2.0（给标准偏好也只有约 52）。
第 3 轮：对这几个基准各做文献级深度诊断（读全文的错误分析、跟进工作、数据格式、我们算力能否跑），找“病因 + 大幅提升的方法”。
