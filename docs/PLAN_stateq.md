## 2. 方法（目标形态）
- 写入：只追加的观察库。通用抽取每段对话为三种操作：OBS（槽位, 值）、RULE（源 → 目标, 新值或空）、RETRACT（槽位）。槽位名由抽取器沿用已有名字；变化写回原槽位。
- 状态：程序维护每个槽位的值历史与状态（KNOWN / UNKNOWN / RETRACTED）；新值触发规则级联（有新值则更新，无新值则标 UNKNOWN 并向下传播）。
- 查询语言（待做）：带聚合的 Datalog 风格算子——current / history / list_all / count / latest / before / exists(带覆盖证书) / changed_since；三值输出，覆盖不足时输出“未知”而非“没有”。
- 读取：读者把问题翻译成查询，程序执行，读者据结果作答；翻译失败回退到阅读原始观察。
